A single-file Swift watcher that screenshots your Roblox window, reads the garage bar with Apple’s on-device OCR, and fires an @everyone Discord alert the moment a rare event appears — then live-edits that same message into a second-by-second countdown.

Download the .swift Setup guide

What it does

Read-only screen capture and OCR. Nothing is injected into Roblox and no memory is read.

🔴💎🌈

Three tracked events

SECRET, DIAMOND and RAINBOW, each with its own emoji in the Discord ping.

📤

Instant alert

Posts as soon as an event and a timer are both readable — it does not wait for the last 20 seconds.

⏱️

Live countdown

One message, edited in place via PATCH, so the channel never gets spammed.

⚡

Adaptive polling

25s idle, 5s once an event is known, 1s under 25 seconds remaining.

🔎

OCR-error tolerant

Levenshtein matching (distance ≤ 2) plus O:/I: digit repair on the clock.

🔄

Cycle detection

When the timer jumps back up, state resets so the next garage gets a fresh ping.

Setup

macOS 13 Ventura or newer, with Xcode or the Swift toolchain installed.

  1. Create a Discord webhook — channel → Edit Channel → Integrations → Webhooks → New Webhook → Copy URL.
  2. Export it as an environment variable. The script refuses to start without it, so the secret never has to live in the file.
  3. Run it with Roblox already open.
  4. Grant Screen Recording when macOS asks: System Settings → Privacy & Security → Screen & System Audio Recording → enable your terminal, then restart the terminal.
export DISCORD_WEBHOOK_URL="https://discord.com/api/webhooks/..."
swift watcher/RobloxEventWatcher.swift

Prefer a standalone binary? Compile it once and run that instead:

swiftc -O watcher/RobloxEventWatcher.swift -o roblox-watcher
./roblox-watcher

Rotate your webhook. The webhook URL that was hard-coded in the earlier version of this script is a password for your channel — anyone holding it can post there. Delete that webhook in Discord, create a new one, and pass it through DISCORD_WEBHOOK_URL. Never commit it.

How it works

One loop, four steps, entirely on-device.

  1. Find the window. SCShareableContent prefers com.roblox.RobloxPlayer above 1000×700, and otherwise falls back to the largest Roblox window.
  2. Capture & crop. SCScreenshotManager grabs the window, then the garage strip is cropped (30–70% across, top 2–13% down) and upscaled 3× with high-quality interpolation so small text survives OCR.
  3. Recognise. VNRecognizeTextRequest runs at .accurate with language correction off — it must not "helpfully" turn RAINBOW into a dictionary word.
  4. Decide. The event name is fuzzy-matched, the clock is parsed by regex as M:SS, and Discord is sent or patched accordingly. At 0:00 the countdown closes and state resets.

A copy of the cropped OCR region can be dumped to /tmp/roblox-debug.png for tuning the crop on your own resolution.
